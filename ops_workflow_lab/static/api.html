로컬 API 문서

가상 대상의 계획 생성·승인·실행 기록을 조회하는 단일 사용자 데모 API입니다.

실행 계획 생성

POST /api/runs · 요청마다 고유한 Idempotency-Key 헤더가 필요합니다. 같은 키와 본문으로 다시 요청하면 저장된 실행을 반환합니다. 

{"goal": "atlas-api 백업해줘", "failure": "none"}

승인·거절·취소

POST /api/runs/{id}/decision · 화면에서 확인한 계획의 해시를 전달합니다. 

{"plan_hash": "실행 응답의 64자리 hash", "decision": "approve"}

approve는 승인, reject는 승인 대기 계획의 거절, cancel은 남은 작업의 취소입니다. 취소해도 이미 완료한 결과는 보존됩니다. 서로 모순되는 결정은 409 오류를 반환합니다.

상태와 이벤트 조회

  • GET /api/health · 서버 모드와 설정된 모델
  • GET /api/targets · 가상 대상 목록
  • GET /api/runs · 최근 30개 실행
  • GET /api/runs/{id} · 계획·단계·결과
  • GET /api/runs/{id}/events?after=0 · 순서 번호 이후의 이벤트
  • GET /api/runs/{id}/stream?after=0 · SSE 실시간 이벤트와 종료 결과. Last-Event-ID 헤더로 재연결할 수 있습니다.

시뮬레이션 시나리오

none: 정상 실행 · transient: 첫 시도 실패 · persistent: 재시도 한도 소진 · verification: 검증 실패. 다중 대상 계획에서는 첫 번째 대상에만 실패 시나리오를 적용합니다.

응답 형식

API 키, 상태 값, JSON은 기술적 호환성을 위해 영문 식별자를 유지합니다. 웹 화면에서는 한국어로 표시합니다. 전체 스키마는 OpenAPI JSON에서 확인할 수 있습니다.

모든 작업 결과는 합성 데이터입니다. 로컬 API는 사용자 인증을 제공하지 않습니다.
