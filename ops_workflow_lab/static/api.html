Local API reference

Single-user synthetic demo. All endpoints return JSON except the event stream.

Endpoints

OpenAPI schema ↗

GET /api/health — runtime mode and planner type.

GET /api/targets — the three fictional servers.

GET /api/runs — the 30 most recent runs.

POST /api/runs — create a plan. Requires an Idempotency-Key header. 

{"goal": "Back up atlas-api", "failure": "transient"}

GET /api/runs/{id} — current state, exact plan hash, and step results.

POST /api/runs/{id}/decision — bind a decision to the reviewed plan. 

{"plan_hash": "<hash returned by the run>", "decision": "approve"}

Use reject to decline a pending plan. Decisions are idempotent; contradictory decisions return 409.

GET /api/runs/{id}/events?after=0 — durable event log.

GET /api/runs/{id}/stream?after=0 — server-sent events. Supports Last-Event-ID.

Failure scenarios: none, transient, persistent, verification. Inventory supports only none.

The API is bound to loopback by the CLI. It has no user accounts, authorization roles, or production infrastructure adapters.
